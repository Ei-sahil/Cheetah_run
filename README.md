# 🐆 Run Cheetah Run

A browser-based endless runner game inspired by classic endless runner games,
built using HTML, CSS and JavaScript.

## 🎮 Live Demo

👉 [Play Run Cheetah Run](https://ei-sahil.github.io/Cheetah_run/)

## ✨ Features

- 🐆 Animated cheetah player
- 🌵 Multiple ground obstacles
- 🦅 Flying eagle obstacles
- 🌅 Dynamic background changes
- 🏃 Continuous running animation
- 🎯 Score system
- 🏆 Highest score saved using Local Storage
- 🎚️ Easy and Hard modes
- 📱 Touch controls for mobile
- 💻 Keyboard controls for desktop

## 🎮 Controls

### Desktop

- `Space` → Jump

### Mobile

- `Tap` → Jump

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Git & GitHub
- GitHub Pages
